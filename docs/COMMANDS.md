# Comandos e Atalhos do NPSharp\n\n## Visão Geral\n\nEste documento lista todos os comandos, atalhos de teclado, menus e ações disponíveis no NPSharp.\n\n## Atalhos de Teclado Globais\n\n### Arquivo\n\n| Atalho | Comando | Classe | Descrição |\n|--------|---------|--------|----------|\n| Ctrl+N | newFile | EditorManager | Criar novo arquivo |\n| Ctrl+O | openFile | EditorManager | Abrir arquivo (FileChooser) |\n| Ctrl+S | save | EditorManager | Salvar arquivo atual |\n| Ctrl+Shift+S | saveAs | EditorManager | Salvar como novo arquivo |\n| Ctrl+W | closeTab | EditorManager | Fechar aba atual |\n| Ctrl+Shift+W | closeAll | EditorManager | Fechar todas as abas |\n\n### Navegação/Edição\n\n| Atalho | Comando | Classe | Descrição |\n|--------|---------|--------|----------|\n| Ctrl+F | find | EditorManager | Buscar no arquivo |\n| Ctrl+H | findReplace | EditorManager | Find e Replace |\n| Ctrl+Shift+F | findWorkspace | SearchPane | Buscar em todos os arquivos |\n| Ctrl+G | goToLine | EditorManager | Ir para linha específica |\n| Ctrl+Shift+P | commandPalette | MainWindow | Abrir palette de comandos (futuro) |\n| Ctrl+Home | goToStart | CodeArea | Ir para início do arquivo |\n| Ctrl+End | goToEnd | CodeArea | Ir para fim do arquivo |\n| Ctrl+/ | toggleLineComment | EditorManager | Comentar/descomentarinha |\n| Ctrl+Shift+/ | toggleBlockComment | EditorManager | Comentar/descomentar bloco |\n| Ctrl+D | duplicateLine | EditorManager | Duplicar linha |\n| Ctrl+Shift+K | deleteLine | EditorManager | Deletar linha |\n| Ctrl+↑ | moveLine Up | EditorManager | Mover linha para cima |\n| Ctrl+↓ | moveLineDown | EditorManager | Mover linha para baixo |\n\n### Interface\n\n| Atalho | Painel | Classe | Descrição |\n|--------|--------|--------|----------|\n| ActivityBarManager | Mostrar/ocultar Git |\n| Ctrl+Shift+D | Debug | ActivityBarManager | Mostrar/ocultar Debug |\n| Ctrl+` | Terminal | ActivityBarManager | Mostrar/ocultar Terminal |\n| Ctrl+J | Ctrl+K Ctrl+O | Open Folder | MainWindow | Abrir workspace |\n\n### Debug\n\n| Atalho | Comando | Classe | Descrição |\n|--------|---------|--------|----------|\n| F5 | start | DebuggerService | IntegratedTerminalPane | Executar programa |\n\n### Git\n\n| Atalho | Comando | Classe | Descrição |\n|--------|---------|--------|----------|\n| Ctrl+Shift+G | showGit | SourceControlPanel | Mostrar Command Palette (Futuro)\n\nQuando implementado, acessar via `Ctrl+Shift+P`:\n\n```\n> command name\n> Toggle Terminal\n> New File\n> Open Folder\n> Format Document\n> Git: Commit\n> Debug: Start\n> Theme: Select Theme\n```\n\n## Customização de Atalhos\n\n### Arquivo de Configuração\n```json\n~/.npsharp/keybindings.json\n\n[\n  {\n    \"key\": \"Ctrl+Alt+O\",\n    \"command\": \"openFile\"\n  },\n  {\n    \"key\": \"Shift+Ctrl+L\",\n    \"command\": \"toggleLineComment\"\n  }\n]\n```\n\n**Classe:** ShortcutManager.java\n\n### Implementação\n```java\nKeyEvent keyEvent = ...\n\nif (keyEvent.isControlDown() && keyEvent.getCode() == KeyCode.N) {\n    editorManager.newFile();\n}\n```\n\n## Atalhos por Sistema Operacional\n\n### Windows\n- `Ctrl` para modificador padrão\n- `Win` para comandos especiais\n- `Alt` para menu bar\n\n### macOS\n- `Cmd` (Command) ao invés de `Ctrl`\n- `Option` (Alt) para variações\n- Menu bar padrão do macOS\n\n### Linux\n- `Ctrl` para modificador padrão\n- Comportamento padrão X11/Wayland\n\n## Ações Sem Atalho\n\nEssas ações acessam via menu:\n\n| Ação | Menu |\n|------|------|\n| New Folder | File Explorer (right-click) |\n| Delete File |
