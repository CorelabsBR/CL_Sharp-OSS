# Idiomas da interface

O NPSharp inicia em `pt-BR` e persiste o idioma em `AppSettings.language`.

O bridge público e restrito expõe a mesma API em Electron, navegador e mobile:

```ts
const languages = await window.npsharp.i18n.availableLanguages();
const current = await window.npsharp.i18n.getLanguage();
await window.npsharp.i18n.setLanguage("en-US");
```

`setLanguage` valida o código aceito, grava a preferência e reconstrói o menu
nativo no desktop. A tela de configurações recarrega a interface após a troca
para que os componentes já abertos também recebam o novo idioma.

Os textos compartilhados ficam em `src/shared/i18n.ts`. Novas strings de
interface devem usar os utilitários de `src/renderer/utils/dom.ts`, que aplicam
a tradução definida para o renderer.
